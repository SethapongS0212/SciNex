In order to help ophthalmologists diagnose eye problems, it is necessary to scan for eye landmarks such as the pupil, the reflection point on the retina, and the boundary of the eye. An individual's eye landmarks on their face can be obtained via some facial landmarks' detection methods, including Haar Cascade. Two problematic aspects of the current approaches, however, are that the pupil and reflection point information is not provided, and the detection is ineffective when confronted with a picture of the upper half of the face or a person wearing a mask. Each deep learning model configuration was set to default settings, except for the flipping parameter, which was fixed at zero to prevent images from flipping to the opposite side. Then all images were fed into RT-DETR model, firstly, the backbone extracts multi-scale features from the input image, then fed into the hybrid encoder. The hybrid encoder transforms the multi-scale features into a sequence of image features through intra-scale interaction and cross-scale fusion. Finally, the IoU-aware query selection is then employed to select a fixed number of image features from the encoder output sequence to serve as initial object queries for the decoder. Finally, the decoder with auxiliary prediction heads iteratively optimizes object queries to generate boxes and confidence scores. The models were trained for 100 epochs.
