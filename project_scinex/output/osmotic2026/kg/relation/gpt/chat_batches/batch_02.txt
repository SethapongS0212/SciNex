Section: Conclusions

Text:
This research aims to develop novel machine learning-based methods for predicting the osmotic and activity coefficients of alkyl ammonium electrolytes. To achieve this objective, the quaternary ammonium salts (Quats) are described using SMILES notation, and a model is constructed using supervised machine learning. Osmotic coefficients obtained from experimental data and activity coefficients calculated by reference sources were compiled for 52 distinct Quats, resulting in a dataset of 1,654 data points. The structural characteristics of these Scientific Reports | (2026) 16:5969 10 | https://doi.org/10.1038/s41598-026-36758-x substances were then encoded using SMILES notation, facilitating numerical analysis by computer algorithms. The dataset includes 14 descriptors , each corresponding to specific structural features. The prepared data is divided into two subsets: the training set and the test set, with proportions of 70% and 30% of the total data, respectively. The training set is utilized to train the machine learning model for predicting osmotic coefficients using seven selected algorithms. The test set is employed to assess the performance of the predictive models generated by these algorithms. Ultimately, it is determined that Gaussian Process (GP) is the optimal algorithm for predicting osmotic coefficients, considering both accuracy and continuity of predictions.
